# Logo Instructions

## Required

Place your Kooperkai Aquatics logo file here:

```
/public/static/logo.png
```

## Logo Specifications

- **File name**: `logo.png` (exactly this name)
- **Format**: PNG (with transparent background preferred) or JPG
- **Size**: 200x200px minimum (300x300px or larger recommended)
- **Design**: Your bulldogs + goldfish crest logo

## Where it appears

Your logo will appear in:
- Website header/navigation (top-left)
- Mobile menu
- Favicon (browser tab icon)

## Favicon (Optional)

For a custom browser tab icon, also add:
```
/public/static/favicon.ico
```

You can create this from your logo using online tools like:
- https://favicon.io
- https://realfavicongenerator.net

## After Adding Logo

1. Place `logo.png` in this directory
2. Rebuild: `npm run build`
3. Redeploy: `npm run deploy` (or push to GitHub)

Your logo will appear automatically!
