# Product Images Directory

Place all product photos here.

## Naming Convention

Use descriptive names with hyphens:
- `electric-blue-acara-1.jpg`
- `electric-blue-acara-2.jpg`
- `neon-tetra-1.jpg`
- `corydoras-catfish-1.jpg`

## Image Guidelines

- **Format**: JPG or PNG
- **Size**: 1000x1000px minimum (larger is better)
- **Quality**: High quality, well-lit photos
- **Background**: Clean, uncluttered backgrounds
- **Multiple angles**: Take 3-4 photos per fish

## Referencing in Google Sheets

In your Google Sheet, reference images as:
```
/static/products/electric-blue-acara-1.jpg
```

For multiple images (comma-separated):
```
/static/products/fish-1.jpg,/static/products/fish-2.jpg,/static/products/fish-3.jpg
```

## Image Optimization (Optional)

Before uploading, you can optimize images:
- Use tools like TinyPNG or ImageOptim
- Target ~200-500KB per image
- Maintain aspect ratio (square preferred)
